Questions people ask

Is eloping cheaper than having a wedding?

On this page the 16 packages print prices from $159 to $4,775 (Monday–Thursday), each from the provider's own website on Oct 28, 2026. A package replaces a venue, an officiant and sometimes photos, so compare it with the venue prices on our city pages.

Does eloping make you legally married?

Only the marriage license and a ceremony by an authorized officiant do; a package is not the license. The licenses we checked cost $35 in New York to $91 in Los Angeles (see each courthouse page for the official wording).

What is the average budget for an elopement?

We do not quote an average. The packages here run $159 to $4,775 (Monday–Thursday), and they include different things, so read the Includes line on each row before you compare.

Is $5,000 enough for a wedding?

For an elopement or micro wedding, yes: every package listed is $4,775 (Monday–Thursday) or less before the license fee ($35 to $91) and any travel. A large guest list is a different budget.

What does an elopement package include?

It depends on the provider: some include only a ceremony site and an officiant, others add photos or flowers. Each row on this page names what the provider's own page lists, and the price covers only that.
