Questions people ask

What is a normal cost for a wedding venue in Chicago?

We do not quote an average, because an average hides what each venue actually prints. On this page 8 venues print prices from $400 to $2,900, each quoted from its own website on Oct 28, 2026.

What are some cheap wedding venues in Chicago under $1,000?

3 of the 8 venues print a price under $1,000: Garfield Park Conservatory: Jensen Room $400; Garden Club of Evanston: Shakespeare Garden $500; Oak Park Conservatory: ceremony only $600. Prices are for the package or hours each venue names, so read the row before you book.

What is a small wedding considered?

There is no official cutoff, so we use each venue's own words: the guest limits printed on this page run from 30 to 100 people. Every venue here prints its price for a small, micro, weekday or elopement booking.

How much does a micro wedding cost in Chicago?

The venue prices we verified run $400 to $2,900. Add the sample finds on this page (a $250 dress, $60 marriage license, $200 flowers, $1,050 photos) to the cheapest venue and you get about $1,960 before catering, rings and tax.

Is $5,000 enough for a wedding in Chicago?

For a small group it can be: the cheapest verified venue ($400) plus the sample finds comes to about $1,960, and even the most expensive venue here is $2,900. A 100-guest wedding is a different budget, because this page prices small groups only.
