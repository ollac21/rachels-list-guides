Buying secondhand safely

  • Measure firstTake your bust, waist and hips, and compare them with the measurements in the listing photos. If a size tag has no measurements, ask the seller.
  • Know the return rulePoshmark says it gives a full refund if an item never ships or does not match the listing description; otherwise all sales are final. You have 72 hours after delivery to open a return case with photos, so inspect the dress before you accept the order (Posh Protect, read Oct 28, 2026).
  • Ask before you buyMessage the seller for more photos, the fabric, and any flaws. A clear answer is a good sign.
  • Plan for a seamstressGet a quote from a local seamstress before you buy: a hem or a bustle is often priced separately from the dress.
